# Carly Automotive Marketplace Platform

A dual-sided automotive marketplace platform designed for **buyers** seeking vehicles and **sellers/dealers** managing inventory and client relationships.

## Documentation Map

All platform documentation is organized under `/docs`:

- **`/docs/architecture`** - Platform architecture, unified marketplace design
- **`/docs/marketplace`** - Road readiness states, filter toggles, state migrations
- **`/docs/listings`** - Listing system, SEO, smart tags, ID format
- **`/docs/publishing`** - Vehicle publish flow, upload validation
- **`/docs/appointments`** - Appointment state machine and lifecycle
- **`/docs/test-drives`** - Test drive system (canonical docs)
- **`/docs/reputation`** - CarlyScore reputation system
- **`/docs/messaging`** - Messaging system architecture
- **`/docs/analytics`** - Analytics and tracking setup
- **`/docs/personalization`** - Preference scoring and personalization
- **`/docs/dealer`** - Dealer portal features
- **`/docs/vehicle`** - Vehicle data, metrics, classifications
- **`/docs/audits`** - Platform health and documentation audits
- **`/docs/_archived`** - Historical documentation (reference only)
- **`/docs/_future`** - Planned AWS migrations and infrastructure guides

See individual folder README files for detailed contents.
